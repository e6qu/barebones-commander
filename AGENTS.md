# Agent Instructions

## Authorship And Attribution

Do not strip authorship or attribution while cleaning code, comments, docs, or
metadata. Preserve copyright headers, upstream notices, license provenance,
`@author` tags, and historical attribution unless the user explicitly asks for a
specific removal and the legal/provenance impact has been considered.

Comment cleanup may update stale technical claims, but it must not erase who
wrote or contributed the original code.
